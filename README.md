# تقویم نمایشگاه‌های مالی، بانکی و پرداخت

داشبورد تقویم نمایشگاه‌ها و همایش‌های مالی، بانکی و پرداخت در ایران و جهان: تاریخ، محل، موضوع، دسته و برگزارکننده.

- `index.html`: صفحهٔ مستقل داشبورد (خط زمانی، جدول، فیلتر ایران/بین‌المللی، ماه و دسته)
- `events.json`: داده‌های رویدادها

## نمایش صفحه

برای لینک ثابت، GitHub Pages را روشن کنید: Settings ← Pages ← Source: `main` / root.
برای اجرای محلی: `python3 -m http.server` و باز کردن `http://localhost:8000`.

## نکته دربارهٔ دقت داده

داده‌ها از خبرگزاری‌ها، سایت برگزارکنندگان و تقویم‌های رویداد جمع شده‌اند. ستون «وضعیت اطلاعات» نشان می‌دهد هر تاریخ چقدر قطعی است. پیش از ثبت‌نام یا سفر، تاریخ و محل را با سایت رسمی رویداد تطبیق دهید.

برای افزودن یا اصلاح رویداد، `events.json` را ویرایش کنید.
